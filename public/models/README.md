# Background removal model

`u2netp.onnx` is the lightweight U²-Net model by Xuebin Qin et al.
(<https://github.com/xuebinqin/U-2-Net>), licensed under the Apache License 2.0.
This copy is the ONNX export published by rembg
(<https://github.com/danielgatis/rembg/releases/download/v0.0.0/u2netp.onnx>,
sha256 `309c8469258dda742793dce0ebea8e6dd393174f89934733ecc8b14c76f4ddd8`).

It runs in the user's browser via onnxruntime-web, so photos never leave the device for background removal.
